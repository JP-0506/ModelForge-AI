One Observation

Your leaderboard contains 9 experiments:

AdaBoost ×3
Random Forest ×2
XGBoost ×4

These are repeated trainings of the same algorithms.

This is expected because your comparison service currently compares every completed experiment, not just the latest run of each algorithm.

So your current behavior is:

Project
    ↓
All Completed Experiments
    ↓
Compare All
Production Recommendation

In a production AutoML platform, you would usually compare only the latest experiment for each algorithm.

Example:

Instead of

AdaBoost
AdaBoost
AdaBoost

you would compare

Latest AdaBoost
Latest Random Forest
Latest XGBoost

Result:

Rank	Algorithm	Score
1	AdaBoost	0.8663
2	Random Forest	0.8609
3	XGBoost	0.8398

This gives a cleaner leaderboard while preserving all historical experiments.
